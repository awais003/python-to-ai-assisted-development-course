
# Python Installation and VS Code Setup

## Introduction

Before starting Python programming, we need a development environment where we can write, execute, and manage Python code.

In this lesson, we set up Python and Visual Studio Code on Windows and prepare everything needed to run our first Python program.

## What You Will Learn

By the end of this lesson, you will know how to:

- Install Python on Windows.
- Install Visual Studio Code.
- Install the Python extension in VS Code.
- Prepare VS Code for Python development.
- Create a Python source file.
- Write and execute your first Python program.

## 1. Install Python

Python is a high-level, general-purpose programming language used for:

- Software development
- Web development
- Automation
- Data analysis
- Artificial intelligence
- Machine learning

Download Python from its official website:

https://www.python.org/downloads/

Follow the installation instructions for Windows.

After installation, verify that Python is available by opening Command Prompt or the VS Code terminal and executing:

```bash
python --version
```

This command displays the installed Python version.

## 2. Install Visual Studio Code

Visual Studio Code (VS Code) is a lightweight source-code editor used to write and manage programs in different programming languages.

Download it from the official website:

https://code.visualstudio.com/

Install Visual Studio Code on your computer.

## 3. Install the Python Extension

VS Code supports programming languages through extensions.

To prepare VS Code for Python development:

1. Open Visual Studio Code.
2. Open the Extensions panel.
3. Search for the Python extension.
4. Install the official Python extension published by Microsoft.

The extension provides Python language support and helps with running and managing Python code.

## 4. Create Your First Python File

After completing the setup:

1. Open a project folder in VS Code.
2. Create a new file.
3. Name it `hello.py`.
4. Add the following code:

```python
print("Hello, World!")
```

Save the file.

## 5. Run Your First Python Program

You can execute your Python program using the VS Code terminal.

Open the terminal and run:

```bash
python hello.py
```

Expected output:

```text
Hello, World!
```

Congratulations! You have successfully created and executed your first Python program.

## Important Concepts

| Tool | Purpose |
|---|---|
| Python | Programming language |
| VS Code | Code editor |
| Python Extension | Python support inside VS Code |
| `.py` | Python source file extension |
| Terminal | Executes Python commands and programs |
